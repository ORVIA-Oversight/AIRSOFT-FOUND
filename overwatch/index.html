PERSISTENT UNITS

Return to your callsign — or go back into the pool.

Campaign units such as Alpha 1-0, Alpha 2-0 and Bravo 1-0 remain persistent even when the player roster changes. Returning players can be offered their previous unit first; unused places return to the event booking pool.

CAMPAIGN BOX

Plan. Configure. Equip. Dispatch. Run.

The managed deployment model uses the planning period to configure software and reusable hardware for the first event. The box can include Starlink or other approved connectivity, command devices, field tablets, power, sensors and optional media modules. Every deployed device should have a unique asset ID, assigned event, configuration state, check-out record and return/check condition. Hardware capability remains market-by-market.
