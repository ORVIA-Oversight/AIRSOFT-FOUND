# Airsoft Found Prototype v1.1 — FOUND RANGE

Static responsive front-end prototype for AIRSOFT FOUND with the FOUND RANGE extension.

## Routes
- `/` — core Airsoft Found marketplace experience
- `/range/` — FOUND RANGE venue discovery, filters, events, demand capture and future flagship concept
- `/range/partners/` — Range Partner programme and demo onboarding

## Prototype rules
All suppliers, venues, availability, prices, partner status, bookings, verification states and activity figures are demo data unless explicitly stated otherwise. No live escrow, payment protection, venue booking or verification integration is claimed.

## Run locally
Open `index.html`, or serve the folder with any static HTTP server.
