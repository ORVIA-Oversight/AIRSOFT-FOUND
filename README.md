# Airsoft Found

Polished responsive front-end prototype based on the Airsoft Found v1.0 build brief.

## Run locally
Open `index.html` directly, or serve the directory with any static server.

## Production direction
This is intentionally front-end only. Next phase can migrate the component structure to Next.js and connect Supabase Auth/PostgreSQL/Storage, Stripe/PayPal provider flows, and ORVIA assurance services.
